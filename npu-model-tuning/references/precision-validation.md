# P7 · 精度校验：输出级对比与逐层 dump

目标：每个优化点都要有**精度影响记录**。默认做输出级对比；异常时再做逐层 dump 定位。精度是硬门——回归的优化点必须回滚。

## 1. 准备参考输出

1. 在**原始代码（开箱状态）**上，用固定输入、固定 seed 跑一次，保存：
   - 最终输出张量（`.pt` / `.npy`）
   - 图像/视频（原始格式）
   - 随机状态（如适用）
2. 用同一份输入和 seed 跑每个优化后的版本，保存候选输出。
3. 对比结果写入 `artifacts/precision/`，每个优化点一份 JSON。

## 2. 输出级对比指标（默认）

| 指标 | 说明 | 适用 |
|---|---|---|
| `max_abs_diff` | 最大绝对误差 | 张量/图像 |
| `mean_abs_diff` | 平均绝对误差 | 张量/图像 |
| `rmse` | 均方根误差 | 张量/图像 |
| `cosine` | 余弦相似度，越接近 1 越一致 | 张量 |
| `rel_l2` | 相对 L2 误差 `||a-b|| / ||a||` | 张量 |
| `psnr` / `ssim` | 图像/视频质量指标 | 图像/视频 |

**判定口径（用户已确认：统一用 cosine）**：

- 主判据：`cosine ≥ 0.999` → **PASS**；`cosine < 0.999` → **FAIL**，回滚或逐层 dump 定位。
- `max_abs_diff`、`mean_abs_diff`、`rmse`、`rel_l2`、`PSNR/SSIM` 照常记录，用于解释差异来源、定位问题和报告说明，**不作为通过与否的第二门槛**。
- 图像/视频保存关键帧对照图供人工检查；肉眼可见异常即使 cosine 达标也要记录并交用户判断。
- 若模型输出使 cosine 在数值上无定义（如全零输出），必须在测试前向用户说明并确认替代口径，不能自行放宽或事后改阈值。
- 不能只凭局部检查通过就宣称"无损"。

`scripts/compare_outputs.py` 支持 `.pt` / `.npy` / 图像文件（`PIL`）对比，输出 JSON + 表格。

## 3. 逐层 dump（异常时）

当输出级对比超阈值或肉眼可见差异时：

1. 用 forward hook 捕获所有子模块的输出统计量（或固定输入下的完整输出）：
   - 对每个命名模块记录 `absmax / mean / std / cosine`（相对基线）
   - 或只记录输出张量的摘要，避免显存爆炸
2. 在原始代码和候选代码上各跑一次同一输入，保存两份 dump。
3. 逐层比较：
   - `rel = ||a - b|| / max(||a||, eps)`
   - `cos = a·b / (||a||·||b||)`
   - 标记首个超过阈值的层（如 `rel > 1e-2`）
4. 重点检查：
   - Norm 层（RMSNorm/LayerNorm）——`npu_rms_norm` 的 fp16/bf16 方差精度问题是常见根因
   - Attention 的 softmax 会放大上游误差
   - dtype cast / layout 转换点
   - 融合算子的参数（mask/scale/rotary_mode）
5. 参考真实案例：Qwen-Image-Edit 的 dump 对比发现 `npu_rms_norm` 把 fp32 输入降为 bf16 后方差误差累积；强制 fp32 RMSNorm 后误差下降。

## 4. 训练侧精度校验

- 用固定数据批次（同一 seed、同一批数据），比较固定 batch 的前向输出（logits / 预测张量）与基线，**主判据同样为 `cosine ≥ 0.999`**。
- 同时记录每步 loss 和 gradient norm 作为辅助监控：在基线正常波动范围内即可；若持续偏离或发散 → 回滚。辅助指标不作为通过门槛。
- 如果训练框架有 `metrics.jsonl` / `summary.json`，用其稳定段数据，不要只看最后一步。
- 若训练流程确实没有可对比的前向输出（如某些纯自监督目标），必须在测试前向用户说明并确认替代口径，不能自行放宽或事后改阈值。
- 混合精度/量化优化要额外检查：loss scale、溢出、NaN。

## 5. 报告写法

每个优化点一节，写明：
- **精度判定方法**：输出级 cosine / 逐层 dump / 训练固定 batch 前向输出 cosine（loss / grad norm 仅作辅助监控）
- **实测结果**：具体数值（不能只写"通过"）
- **判定结论**：通过 / 可接受（附条件）/ 回滚
- **备注**：哪些检查覆盖了哪些样本、尺寸、层；没有覆盖到的要明确说明
