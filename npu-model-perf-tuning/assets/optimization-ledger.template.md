# 优化台账 `optimization_ledger.md`

每做一次实验就记一行。它是最终报告 §5「优化点汇总」与 §8「高侵入候选」的数据来源。

## 记录规则
- 每次只改一个变量（一次一行）。
- `提升%` 写**相对当时基线**的单点增量，并注明口径（warmup/步数/多卡）。
- `状态`：已固化 / 已否决 / ⚠️待决策。
- 待决策项**必须**同时进「待决策清单」汇总给用户。
